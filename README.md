# `CXX_UNIT`
> C++17 Standard CXX Entities Namespace

This project is simply a namespace wrapper for standard C++ entities under `son8::cxx` namespace for **C++17**.

Entities that mark deprecated or removed prior to `c++26` standard are not available under `son8::cxx` namespace

Entities are split into eight units:

- `core.hxx`: _Structural andor Core Features_ (**included by every other unit**)
- `atom.hxx`: _Concurrency andor Atomic Operations_
- `data.hxx`: _Memory andor Data Structures_
- `file.hxx`: _Streams andor File Systems_
- `flow.hxx`: _Exceptions andor Flow Control_
- `func.hxx`: _Mathematics andor Functional Algorithms_
- `meta.hxx`: _Compile-time andor Meta Programming_
- `text.hxx`: _Strings andor Text Processing_
